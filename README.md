# Herfect.github.io

The public website for Herfect, served by GitHub Pages at https://herfect.github.io/.

The site is plain HTML, CSS and a little JavaScript with no build step. Its source lives in the `website/` folder of the Herfect app repository; this repository holds the published copy. To publish a change, copy `website/` here (without its README) and push to `main`.

Preview locally:

```sh
python3 -m http.server
```
